# 🌾 AgroCitypremium

## Descrição do Projeto

AgroCity é um simulador educativo desenvolvido para o Concurso Agrinho 2026. O objetivo é permitir que o usuário administre uma cidade agrícola sustentável, tomando decisões relacionadas à produção de alimentos, preservação ambiental e utilização de energias renováveis.

Ao longo da experiência, o jogador constrói fazendas, cria reservas ambientais, instala energia solar e gerencia recursos financeiros, buscando o equilíbrio entre desenvolvimento econômico e sustentabilidade.

---

## Objetivo do Projeto

Demonstrar como a tecnologia e a gestão sustentável podem contribuir para o desenvolvimento do agronegócio, promovendo a conscientização sobre a importância da preservação ambiental e do uso responsável dos recursos naturais.

## Como Executar

### Executar Localmente

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html`.
4. Utilize os botões para administrar sua cidade agrícola.

### Executar Online

Acesse a versão publicada pelo GitHub Pages através do link disponível no repositório.

## Relação com o Tema Agrinho 2026

### Tema:

**Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente.**

O AgroCity está diretamente relacionado ao tema do Concurso Agrinho 2026, pois apresenta uma simulação em que o usuário precisa equilibrar a produção agrícola, o crescimento econômico e a preservação ambiental. O projeto demonstra que o desenvolvimento sustentável é fundamental para garantir recursos naturais para as futuras gerações, fortalecendo o agronegócio de forma responsável e consciente.
